# blackout

Гасить екран Mac без вимкнення дисплея: яскравість вбудованого дисплея ставиться на 0, а всі екрани закриваються чорним вікном. Будь-яка клавіша, рух миші, клік чи дотик до трекпада повертають попередню яскравість.

Навіщо: `pmset displaysleepnow` справді вимикає дисплей, але при налаштуванні «вимагати пароль одразу» разом із ним блокується сесія, і FortiClient VPN розриває тунель. `blackout` дисплей не вимикає, тож сесія не блокується і VPN лишається підключеним.

## Встановлення

```bash
make install
```

Потрібен `swiftc` (Xcode Command Line Tools). Команда ставиться в `~/.local/bin/blackout`.

## Використання

```bash
blackout
```

## Як працює

- Яскравість читається і змінюється через приватний фреймворк `DisplayServices`.
- Поки команда працює, вона тримає `PreventUserIdleDisplaySleep`, щоб дисплей не заснув.
- Дію користувача видно за лічильником `HIDIdleTime` з `IOHIDSystem`: коли він скидається, яскравість повертається. Події вікна для цього не використовуються, бо вікно може втратити фокус (заставка, сповіщення, інший застосунок), і тоді натискання до нього не доходять.
- Якщо екран блокується або вмикається заставка (`com.apple.screenIsLocked`, `com.apple.screensaver.didstart`), яскравість повертається одразу, щоб було видно поле пароля.
- `SIGINT`, `SIGTERM`, `SIGHUP` теж повертають яскравість.

## Обмеження

- Яскравість змінюється лише на вбудованому дисплеї. Зовнішній монітор стає чорним, але його підсвітка лишається ввімкненою.
- Якщо екран лишився темним, натисніть клавішу збільшення яскравості (F2): вона працює незалежно від `blackout`.
