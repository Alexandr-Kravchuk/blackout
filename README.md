# blackout

Гасить екрани Mac без сну дисплея: підсвітка вбудованого дисплея вимикається (яскравість 0), зовнішні дисплеї від'єднуються від macOS і переходять у standby. Будь-яка клавіша, рух миші, клік чи дотик до трекпада повертають усе назад.

Навіщо: `pmset displaysleepnow` справді вимикає дисплей, але при налаштуванні «вимагати пароль одразу» разом із ним блокується сесія, і FortiClient VPN розриває тунель. `blackout` сон дисплея не вмикає, тож сесія не блокується і VPN лишається підключеним.

## Встановлення

```bash
make install
```

Потрібен `swiftc` (Xcode Command Line Tools). Команда ставиться в `~/.local/bin/blackout`.

Іконка в панелі меню і гаряча клавіша:

```bash
make install-menubar
```

Ціль ставить команду і LaunchAgent `com.alexandr-kravchuk.blackout`, який запускає `blackout --menubar` при кожному вході в систему. Прибрати — `make uninstall-menubar`.

Кнопка в Control Center:

```bash
make install-shortcut
```

1. Натисніть «Add Shortcut» у вікні Shortcuts.
2. Увімкніть Shortcuts → Settings → Advanced → Allow Running Scripts.
3. Відкрийте Control Center → Edit Controls → Shortcuts → виберіть «Blackout» і перетягніть кнопку на потрібне місце.

Кнопка виконує `blackout --trigger`: команда надсилає процесу іконки `SIGUSR1`, і він запускає затемнення, як ⌃⌥⌘B. Якщо процесу іконки немає, затемнення запускається в самій команді.

## Використання

```bash
blackout
```

З панелі меню: іконка місяця праворуч зверху → «Погасити екрани», або ⌃⌥⌘B з будь-якого застосунку. Пункт «Підключити всі дисплеї» виконує `blackout --restore`.

Якщо затемнення запущене з іконки, кнопки чи ⌃⌥⌘B і завершилось аварійно, процес іконки сам підключає всі дисплеї. Якщо аварійно завершився `blackout`, запущений з термінала, і зовнішній дисплей лишився вимкненим, виконайте з іншого пристрою (ssh) або наосліп:

```bash
blackout --restore
```

Команда підключає всі дисплеї. Інший спосіб — перепідключити кабель дисплея.

## Як працює

- Екрани гаснуть після 0,5 с без дій користувача: інакше відпускання Enter чи ⌃⌥⌘B одразу повернуло б усе назад.
- `--menubar` реєструє ⌃⌥⌘B через Carbon `RegisterEventHotKey`: дозвіл Accessibility для цього не потрібен. Якщо комбінацію вже зайняв інший застосунок, лишається тільки пункт меню. Кожне затемнення — окремий процес `blackout`.
- Яскравість вбудованого дисплея читається і змінюється через приватний фреймворк `DisplayServices`.
- Зовнішні дисплеї від'єднуються приватною функцією `CGSConfigureDisplayEnabled` (SkyLight), як «Disconnect» у BetterDisplay. На Apple silicon дисплей без сигналу переходить у standby і підсвітка гасне. Конфігурація застосовується з `.forAppOnly`, але на macOS 27 після `kill -9` дисплей лишається від'єднаним (перевірено 2026-10-28). Тому процес іконки стежить за кожним затемненням і після аварійного завершення підключає всі дисплеї.
- Яскравість для зовнішнього дисплея не підходить. Studio Display керує яскравістю через USB HID (Monitor Control, VESA VCP `0x10`), і найменше значення в його HID-дескрипторі — 400 з 60000. На 400 підсвітка світить, а команди вимкнення живлення (VCP `0xD6`) дескриптор не має.
- Коли кришка закрита і вбудованого дисплея немає, перед від'єднанням створюється віртуальний дисплей (приватний `CGVirtualDisplay`, як у FluffyDisplay і BetterDisplay) з режимом фізичного. Без жодного дисплея macOS може приспати Mac у clamshell-режимі, а сон розриває VPN. Вікна на час blackout переїжджають на віртуальний дисплей. Із `--menubar` віртуальний дисплей тримає процес іконки: якщо віртуальний дисплей зникає разом з аварійно завершеним процесом затемнення, macOS забуває від'єднаний зовнішній дисплей, і його повертає лише перепідключення кабелю.
- Не вдалося створити віртуальний дисплей або від'єднати зовнішній — дисплей лишається під мінімальною яскравістю і чорним вікном, як раніше.
- Поки команда працює, вона тримає `PreventUserIdleDisplaySleep`, щоб дисплей не заснув.
- Дію користувача видно за лічильником `HIDIdleTime` з `IOHIDSystem`: коли він скидається, яскравість повертається. Події вікна для цього не використовуються, бо вікно може втратити фокус (заставка, сповіщення, інший застосунок), і тоді натискання до нього не доходять.
- Якщо екран блокується або вмикається заставка (`com.apple.screenIsLocked`, `com.apple.screensaver.didstart`), яскравість повертається одразу, щоб було видно поле пароля.
- `SIGINT`, `SIGTERM`, `SIGHUP` теж повертають усе назад.

## Обмеження

- Після повернення macOS може розставити вікна інакше, ніж до blackout.
- `CGSConfigureDisplayEnabled` і `CGVirtualDisplay` — приватні API, нова версія macOS може їх змінити.
- Якщо екран лишився темним, натисніть клавішу збільшення яскравості (F2): вона працює незалежно від `blackout`.
